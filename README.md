# 🌿 Olibea – Olive Tree Global Resource

**Olibea** is a modern, fully multilingual static website dedicated to the olive tree — its cultivation, health benefits, culinary uses, and cultural significance.

Built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, and deployed on **Vercel**, it supports **7 languages** with full SEO optimization, including `hreflang` tags and localized metadata.

---

## 🚀 Key Features

- 🌍 **7 Languages**: English, Arabic, Italian, French, Japanese, Chinese, Korean.
- ⚡ **Blazing Fast**: Static generation (SSG) and Incremental Static Regeneration (ISR) for speed.
- 🔍 **SEO Optimized**:
  - `hreflang` tags for international targeting.
  - Localized meta titles & descriptions.
  - Clean URL structure (`/en/benefits`, `/ar/فوائد`).
- 🎨 **Modern UI**: Responsive design with Tailwind CSS.
- 🧩 **Highly Modular**: Easy to extend with new pages and languages.
